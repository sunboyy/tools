Disclaimer — use with caution. This page is an unofficial demonstration of the dice-roll seed generation method popularised by hardware wallets. It is not affiliated with, endorsed by, or verified against any vendor or device, and nothing here is a recommendation of any particular hardware wallet — check the current security track record of any device yourself before trusting it with funds. A web browser is not a secure environment for key material: the page, your OS, and anything watching the screen or keyboard can see the result. For real funds, generate the seed on a dedicated offline device you have independently vetted, and treat anything produced here as untrusted and for learning only.
Read first. Use real, fair dice — not the keyboard, not a "random" thought. Each roll is appended to the roll string and the whole string is re-hashed, so the phrase changes with every entry. Anyone who sees your rolls can recreate this phrase.
